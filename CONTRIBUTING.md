# Contributing Guidelines

Thank you for your interest in contributing to AI Virtual Mouse!

## How to Contribute
1. Fork the repository and create your branch from main.
2. Ensure Python 3.10+ is installed and all dependencies in equirements.txt are satisfied.
3. Test your changes locally to ensure zero-jitter mouse tracking.
4. Follow PEP 8 style guidelines.
5. Submit a pull request with a clear description of your improvements.
